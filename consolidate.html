Sum Two or More Similar Product Name Price Values in Excel

You can follow these steps:

  1. Define your data
  2. Go to data menu
  3. And click on Consolidate button
  4. Select the Sum option from Function dropdown box
  5. Select the Cell Reference (Example - A1:C16)
  6. Check the top row and left column box
  7. Then click on Ok button

Excel मा एउटै नाम भएका वस्तु (Product) हरूको कुल रकम (Total Price) कसरी निकाल्ने ?

Microsoft Excel मा एउटै नाम भएका वस्तु वा सामानहरू धेरै पटक प्रविष्ट गरिएको अवस्थामा तिनीहरूको मूल्य (Price) वा रकम (Amount) लाई एकै ठाउँमा जम्मा (Sum) गर्न Consolidate Feature प्रयोग गर्न सकिन्छ।

उदाहरणका लागि कुनै बिक्री विवरण (Sales Report) मा "Laptop", "Printer", "Mouse" जस्ता वस्तुहरू धेरै पटक दोहोरिएका छन् भने प्रत्येक वस्तुको कुल बिक्री रकम अलग-अलग गणना गर्न Consolidate Feature निकै उपयोगी हुन्छ।

Consolidate Feature के हो ?

Consolidate भनेको Excel को एउटा विशेष सुविधा हो जसले विभिन्न पङ्क्ति, स्तम्भ वा तालिकामा रहेका समान (Similar) डाटालाई एकीकृत (Combine) गरी कुल योग (Sum), Average, Count, Max, Min आदि निकाल्न मद्दत गर्दछ।

यदि एउटै Product Name धेरै पटक दोहोरिएको छ भने Consolidate ले ती सबै डेटालाई एकत्रित गरेर कुल रकम देखाउन सक्छ।

उदाहरण डेटा

Product Qty Price
Laptop 1 50000
Printer 1 15000
Laptop 1 60000
Mouse 2 2000
Printer 1 12000

यस उदाहरणमा Laptop र Printer दुई पटक दोहोरिएका छन्। Consolidate प्रयोग गरेपछि परिणाम यसरी देखिन सक्छ:

Product Total Price
Laptop 110000
Printer 27000
Mouse 2000

Consolidate प्रयोग गर्ने चरणहरू

Step 1: Data तयार गर्नुहोस्

सबै Product Name, Quantity तथा Price सही तरिकाले Excel Sheet मा व्यवस्थित गर्नुहोस्।

Step 2: Data Menu मा जानुहोस्

Excel को माथिल्लो Menu Bar बाट Data Tab खोल्नुहोस्।

Step 3: Consolidate Button मा Click गर्नुहोस्

Data Tab भित्र रहेको Consolidate Option मा Click गर्नुहोस्।

Step 4: Function चयन गर्नुहोस्

Consolidate Dialog Box खुल्नेछ। Function Dropdown बाट Sum चयन गर्नुहोस्।

यदि Average, Count, Max, Min आदि निकाल्न चाहनुहुन्छ भने अन्य Function पनि चयन गर्न सकिन्छ।

Step 5: Cell Reference चयन गर्नुहोस्

Reference Box मा आफ्नो Data Range चयन गर्नुहोस्। 

Example:
A1:C16

Range चयन गरेपछि Add Button मा Click गर्नुहोस्।

Step 6: Top Row र Left Column Check गर्नुहोस्

Dialog Box को तल रहेको:

  • Top Row
  • Left Column

दुवै Checkbox मा Tick लगाउनुहोस्।

यसले Excel लाई पहिलो Row Header र पहिलो Column Label को आधारमा समान Product हरू पहिचान गर्न मद्दत गर्छ।

Step 7: OK Button मा Click गर्नुहोस्

अब OK Button मा Click गर्नुहोस्।

Excel ले समान Product Name भएका सबै Record हरूलाई एकत्रित गरी Total Price निकालेर नयाँ Result देखाउनेछ।

Consolidate प्रयोग गर्दा प्राप्त हुने फाइदाहरू

  • समान Product को कुल रकम छिटो निकाल्न सकिन्छ।
  • ठूलो Sales Report सजिलै विश्लेषण गर्न सकिन्छ।
  • Manual Calculation गर्नुपर्दैन।
  • समय बचत हुन्छ।
  • Data Summary Report तयार गर्न सजिलो हुन्छ।
  • विभिन्न Sheet का Data समेत Merge गर्न सकिन्छ।

वैकल्पिक तरिका – Pivot Table प्रयोग गर्ने

यदि Data धेरै ठूलो छ भने Pivot Table प्रयोग गरेर पनि Product अनुसार Total Amount निकाल्न सकिन्छ।

  • Data Select गर्नुहोस्।
  • Insert → Pivot Table मा जानुहोस्।
  • Product लाई Rows मा राख्नुहोस्।
  • Price लाई Values मा राख्नुहोस्।
  • Sum of Price स्वतः प्राप्त हुन्छ।

Pivot Table सामान्यतया Consolidate भन्दा बढी शक्तिशाली र Flexible मानिन्छ।

महत्वपूर्ण सावधानीहरू

  • Product Name एकदम समान हुनुपर्छ।
  • "Laptop" र "Laptop " (Space सहित) फरक मानिन सक्छ।
  • Header Row सही हुनुपर्छ।
  • Price Column Number Format मा हुनुपर्छ।
  • Blank Row वा Blank Column भए परिणाम फरक आउन सक्छ।
छिटो सम्झनुहोस्:

1. Data तयार गर्नुहोस्
2. Data Menu → Consolidate
3. Function = Sum
4. Range Select (A1:C16)
5. Add Button Click
6. Top Row ✔
7. Left Column ✔
8. OK Click

यसरी Excel ले एउटै नाम भएका Product हरूको Price वा Amount लाई स्वतः जोडेर (Sum) कुल रकम निकालिदिन्छ।
