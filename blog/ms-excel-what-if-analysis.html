MS Excel मा What-If Analysis के हो ?

What-If Analysis Microsoft Excel को एक शक्तिशाली सुविधा (Feature) हो जसले कुनै तथ्यांक (Data) वा सूत्र (Formula) मा परिवर्तन गर्दा परिणाम (Result) कसरी परिवर्तन हुन्छ भन्ने विश्लेषण गर्न मद्दत गर्दछ।

सरल भाषामा भन्नुपर्दा, "यदि यस्तो भयो भने के हुन्छ?" भन्ने प्रश्नको उत्तर खोज्न What-If Analysis प्रयोग गरिन्छ।

उदाहरणका लागि:

  • तलब १०% बढेपछि कति हुन्छ ?
  • बिक्री २०% घटेमा नाफा कति हुन्छ ?
  • ब्याजदर परिवर्तन हुँदा ऋणको किस्ता कति हुन्छ ?
  • परीक्षामा थप ५ अंक आएमा ग्रेड परिवर्तन हुन्छ कि हुँदैन ?

यस्ता विभिन्न सम्भावित अवस्थाहरू (Scenarios) को विश्लेषण गर्न What-If Analysis प्रयोग गरिन्छ।

What-If Analysis कहाँ पाइन्छ ?

Excel मा: 

Data Tab → Forecast Group → What-If Analysis

What-If Analysis भित्र मुख्यतया ३ वटा उपकरण (Tools) उपलब्ध हुन्छन्:

  • Scenario Manager
  • Goal Seek
  • Data Table

१. Scenario Manager

Scenario Manager के हो ?

Scenario Manager प्रयोग गरेर एउटै डेटा सेटमा विभिन्न सम्भावित अवस्थाहरू (Scenarios) बनाएर तुलना गर्न सकिन्छ।

उदाहरण:

  • Best Case (उत्तम अवस्था)
  • Normal Case (सामान्य अवस्था)
  • Worst Case (खराब अवस्था)

उदाहरण

विवरण रकम
बिक्री 100000
खर्च 70000
नाफा 30000

अब तपाईं विभिन्न बिक्री रकम राखेर नाफा कति हुन्छ भनेर तुलना गर्न सक्नुहुन्छ।

Scenario Manager प्रयोग गर्ने तरिका

  1. Data Tab मा जानुहोस्।
  2. What-If Analysis क्लिक गर्नुहोस्।
  3. Scenario Manager चयन गर्नुहोस्।
  4. Add क्लिक गर्नुहोस्।
  5. Scenario Name दिनुहोस्।
  6. Change Cells चयन गर्नुहोस्।
  7. नयाँ मान (Value) राख्नुहोस्।
  8. OK क्लिक गर्नुहोस्।
  9. Show क्लिक गरी परिणाम हेर्नुहोस्।

२. Goal Seek

Goal Seek के हो ?

Goal Seek ले कुनै निश्चित लक्ष्य (Goal) प्राप्त गर्न कुन मान परिवर्तन गर्नुपर्छ भन्ने पत्ता लगाउँछ।

अर्थात् परिणाम थाहा छ तर त्यसमा पुग्न आवश्यक इनपुट थाहा छैन भने Goal Seek प्रयोग गरिन्छ।

उदाहरण

तपाईंको मासिक बिक्री रु. ५०,००० छ। प्रति वस्तु मूल्य रु. ५०० छ।

अब तपाईं जान्न चाहनुहुन्छ:

रु. १,००,००० बिक्री गर्न कति वस्तु बेच्नुपर्छ ?

Goal Seek ले स्वतः उत्तर निकालिदिन्छ।

Goal Seek प्रयोग गर्ने तरिका

  1. Formula भएको Cell चयन गर्नुहोस्।
  2. Data → What-If Analysis → Goal Seek
  3. Set Cell मा Formula Cell चयन गर्नुहोस्।
  4. To Value मा लक्ष्य परिणाम राख्नुहोस्।
  5. By Changing Cell मा परिवर्तन हुने Cell चयन गर्नुहोस्।
  6. OK क्लिक गर्नुहोस्।

उदाहरण

Quantity Rate Total
100 500 =A2*B2

Goal Seek प्रयोग गरेर Total = 100000 राख्दा Quantity स्वतः 200 देखाउँछ।

३. Data Table

Data Table के हो ?

Data Table ले एउटै Formula को धेरै सम्भावित परिणामहरू एकै पटक देखाउँछ।

यदि एउटै Formula मा विभिन्न Input राख्दा परिणाम कति आउँछ भन्ने हेर्न Data Table प्रयोग गरिन्छ।

उदाहरण

ब्याजदर परिवर्तन हुँदा ऋणको किस्ता कति हुन्छ ?

वा

विभिन्न अंक प्राप्त गर्दा विद्यार्थीको प्रतिशत कति हुन्छ ?

Data Table प्रयोग गर्ने तरिका

  1. Formula तयार गर्नुहोस्।
  2. सम्भावित मानहरूको सूची बनाउनुहोस्।
  3. पूरै Range चयन गर्नुहोस्।
  4. Data → What-If Analysis → Data Table
  5. Input Cell चयन गर्नुहोस्।
  6. OK क्लिक गर्नुहोस्।

Excel ले सबै परिणामहरू एकै पटक निकालिदिन्छ।

What-If Analysis को वास्तविक प्रयोग

१. व्यवसाय (Business)

  • नाफा-नोक्सान विश्लेषण
  • बिक्री अनुमान
  • बजेट योजना
  • लगानी विश्लेषण

२. बैंक तथा वित्तीय संस्था

  • EMI गणना
  • ऋण विश्लेषण
  • ब्याजदर प्रभाव अध्ययन

३. विद्यालय तथा कलेज

  • नतिजा विश्लेषण
  • ग्रेड गणना
  • अंक परिवर्तनको प्रभाव

४. सरकारी कार्यालय

  • बजेट अनुमान
  • राजस्व प्रक्षेपण
  • परियोजना लागत विश्लेषण

What-If Analysis का फाइदाहरू

  • भविष्यको अनुमान गर्न सकिन्छ।
  • निर्णय लिन सजिलो हुन्छ।
  • विभिन्न विकल्प तुलना गर्न सकिन्छ।
  • समय बचत हुन्छ।
  • जोखिम विश्लेषण गर्न मद्दत गर्छ।
  • व्यवसायिक योजना बनाउन उपयोगी हुन्छ।

What-If Analysis र Formula बीचको फरक

Formula What-If Analysis
सामान्य गणना गर्छ विभिन्न सम्भावित परिणाम विश्लेषण गर्छ
एउटा Result दिन्छ धेरै Result तुलना गर्न सक्छ
स्थिर Calculation Scenario आधारित Calculation
Manual परिवर्तन गर्नुपर्छ स्वचालित विश्लेषण गर्छ

महत्त्वपूर्ण सुझाव

नोट: यदि तपाईं Budget Planning, Salary Calculation, Loan Analysis, Business Forecasting, Student Result Analysis, Revenue Projection वा Financial Planning सम्बन्धी Excel File बनाउँदै हुनुहुन्छ भने What-If Analysis को प्रयोगले धेरै समय बचत गर्नुका साथै सही निर्णय लिन मद्दत गर्दछ।
