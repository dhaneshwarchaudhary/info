Microsoft Word मा Page Break र Section Break के हो ?

Microsoft Word मा लामो Document तयार गर्दा एउटै Document लाई विभिन्न पृष्ठ तथा भागमा व्यवस्थित गर्न Page Break र Section Break को प्रयोग गरिन्छ। यी दुवैको काम Document लाई व्यवस्थित बनाउनु हो, तर दुवैको उद्देश्य फरक हुन्छ।

१. Page Break भनेको के हो ?

Page Break भनेको हाल लेखिरहेको स्थानदेखि अगाडिको सामग्रीलाई नयाँ Page बाट सुरु गराउने सुविधा हो। उदाहरणका लागि तपाईंले एउटा अध्यायको लेखाइ पूरा गरेपछि अर्को अध्याय नयाँ पृष्ठबाट सुरु गर्न चाहनुभयो भने Page Break प्रयोग गर्न सकिन्छ।

Page Break प्रयोग गरेपछि Cursor रहेको स्थानपछि आउने सामग्री स्वतः अर्को पृष्ठबाट सुरु हुन्छ।

सरल उदाहरण

मानौं तपाईंले एउटा Report तयार गर्दै हुनुहुन्छ:

  • Page 1 – Introduction
  • Page 2 – Objectives
  • Page 3 – Methodology
  • Page 4 – Conclusion

Introduction सकिएपछि Objectives लाई नयाँ Page बाट सुरु गर्न Page Break प्रयोग गर्न सकिन्छ।

२. Page Break कसरी राख्ने ?

तरिका १: Insert Menu बाट

  1. Microsoft Word खोल्नुहोस्।
  2. जहाँबाट नयाँ Page सुरु गर्न चाहनुहुन्छ त्यहाँ Cursor राख्नुहोस्।
  3. Insert Menu मा क्लिक गर्नुहोस्।
  4. Page Break मा क्लिक गर्नुहोस्।
  5. Cursor पछिको सामग्री नयाँ Page बाट सुरु हुन्छ।

तरिका २: Keyboard Shortcut

Page Break राख्ने सबैभन्दा सजिलो तरिका:

Ctrl + Enter

अर्थात् Keyboard मा Ctrl थिचेर Enter थिच्दा नयाँ Page सुरु हुन्छ।

३. Page Break र सामान्य Enter बीचको फरक

धेरै प्रयोगकर्ताले नयाँ पृष्ठमा सामग्री लैजान धेरै पटक Enter थिच्ने गर्छन्। यो सही तरिका होइन।

धेरै पटक Enter थिचेर नयाँ Page बनाउँदा Document को Formatting बिग्रिन सक्छ। पछि अगाडिको सामग्री थप्दा वा हटाउँदा Page को स्थिति परिवर्तन हुन सक्छ।

त्यसैले नयाँ Page सुरु गर्न सधैं Page Break प्रयोग गर्नु राम्रो हुन्छ।

४. Section Break भनेको के हो ?

Section Break भनेको एउटै Word Document लाई विभिन्न Section मा विभाजन गर्ने सुविधा हो। Section Break को विशेषता के हो भने प्रत्येक Section को Page Setup तथा Formatting अलग-अलग राख्न सकिन्छ।

उदाहरणका लागि एउटै Document मा पहिलो भागमा Portrait Page र अर्को भागमा Landscape Page चाहियो भने Section Break प्रयोग गर्न सकिन्छ।

५. Section Break किन प्रयोग गर्ने ?

Section Break विशेषगरी निम्न अवस्थामा उपयोगी हुन्छ:

  • एउटै Document मा Portrait र Landscape Page राख्न।
  • अलग-अलग Header राख्न।
  • अलग-अलग Footer राख्न।
  • Page Number को Format परिवर्तन गर्न।
  • Document को कुनै भागमा फरक Margin राख्न।
  • Column को संख्या परिवर्तन गर्न।
  • अलग-अलग Page Orientation प्रयोग गर्न।
  • Document का विभिन्न भागलाई स्वतन्त्र रूपमा Format गर्न।

६. Section Break का प्रकारहरू

Microsoft Word मा मुख्य रूपमा चार प्रकारका Section Break उपलब्ध हुन्छन्।

१. Next Page

Next Page ले नयाँ Section लाई अर्को नयाँ Page बाट सुरु गर्छ।

उदाहरण:

  • Section 1 – Portrait
  • Section Break – Next Page
  • Section 2 – Landscape

यो विकल्प Report, Thesis तथा Project Document मा धेरै उपयोगी हुन्छ।

२. Continuous

Continuous Section Break ले नयाँ Section सुरु गर्छ तर नयाँ Page सुरु गर्दैन। अर्थात् त्यही Page बाट अर्को Section सुरु हुन्छ।

उदाहरणका लागि एउटै Page मा एउटा भागलाई दुई Column र अर्को भागलाई एक Column बनाउन Continuous Section Break उपयोगी हुन्छ।

३. Even Page

Even Page ले नयाँ Section लाई अर्को Even-numbered Page बाट सुरु गर्छ।

पुस्तक, Thesis वा दुईतर्फी Printing हुने Document तयार गर्दा यसको प्रयोग उपयोगी हुन्छ।

४. Odd Page

Odd Page ले नयाँ Section लाई अर्को Odd-numbered Page बाट सुरु गर्छ।

पुस्तक वा Chapter लाई सधैं दायाँतर्फको Page अर्थात् Odd Page बाट सुरु गराउन यसको प्रयोग गर्न सकिन्छ।

७. Section Break कसरी राख्ने ?

  1. Microsoft Word Document खोल्नुहोस्।
  2. जहाँ Section छुट्याउन चाहनुहुन्छ त्यहाँ Cursor राख्नुहोस्।
  3. Layout Menu मा जानुहोस्।
  4. Breaks मा क्लिक गर्नुहोस्।
  5. Section Break अन्तर्गत आवश्यक विकल्प छान्नुहोस्।
  6. Next Page, Continuous, Even Page वा Odd Page चयन गर्नुहोस्।

८. Page Break र Section Break बीचको फरक

विषय Page Break Section Break
मुख्य उद्देश्य नयाँ Page सुरु गर्नु Document लाई फरक Section मा विभाजन गर्नु
Formatting सामान्यतया एउटै Formatting कायम रहन्छ प्रत्येक Section को Formatting फरक राख्न सकिन्छ
Page Orientation अलग गर्न प्रयोग हुँदैन Portrait/Landscape फरक राख्न सकिन्छ
Header/Footer Section परिवर्तन हुँदैन Section अनुसार फरक गर्न सकिन्छ
Shortcut Ctrl + Enter प्रत्यक्ष Shortcut छैन

९. एउटै Document मा Portrait र Landscape कसरी राख्ने ?

यो Section Break को सबैभन्दा महत्वपूर्ण प्रयोगमध्ये एक हो। उदाहरणका लागि तपाईंको Report मा धेरै ठूलो Table छ र त्यो Landscape Page मा मात्र राम्रोसँग अट्छ।

  1. Landscape बनाउनुपर्ने Table भन्दा अगाडि Cursor राख्नुहोस्।
  2. Layout → Breaks → Section Breaks → Next Page चयन गर्नुहोस्।
  3. अब Landscape बनाउनुपर्ने Page मा Cursor राख्नुहोस्।
  4. Layout → Orientation → Landscape चयन गर्नुहोस्।
  5. Landscape Section पछि फेरि Section Break राख्नुहोस्।
  6. अर्को Section लाई Portrait मा राख्नुहोस्।

यसरी एउटै Word Document मा केही Page Portrait र केही Page Landscape बनाउन सकिन्छ।

१०. Header र Footer मा Section Break को प्रयोग

लामो Report वा Thesis मा प्रत्येक Chapter को Header फरक राख्नुपर्ने हुन सक्छ। यस्तो अवस्थामा Section Break अत्यन्त उपयोगी हुन्छ।

Section Break राखेपछि Header वा Footer खोल्दा Link to Previous भन्ने विकल्प देखिन्छ। यसलाई बन्द गरेपछि उक्त Section को Header/Footer लाई अघिल्लो Section भन्दा फरक बनाउन सकिन्छ।

११. Page Number मा Section Break को प्रयोग

Thesis, Research Report वा पुस्तक तयार गर्दा सुरुका Page मा Roman Number अर्थात् i, ii, iii र मुख्य भागमा 1, 2, 3 राख्नुपर्ने हुन सक्छ।

यस्तो अवस्थामा Section Break प्रयोग गरेर दुईवटा Section बनाउन सकिन्छ र प्रत्येक Section मा फरक Page Number Format राख्न सकिन्छ।

१२. Page Break र Section Break कहिले प्रयोग गर्ने ?

Page Break प्रयोग गर्नुहोस् यदि:

  • नयाँ Chapter नयाँ Page बाट सुरु गर्नुपर्छ।
  • नयाँ विषय नयाँ Page बाट सुरु गर्नुपर्छ।
  • Cover Page पछि अर्को Page सुरु गर्नुपर्छ।
  • सामग्रीलाई निश्चित Page बाट सुरु गराउनुपर्छ।

Section Break प्रयोग गर्नुहोस् यदि:

  • Portrait र Landscape Page एउटै Document मा चाहिन्छ।
  • Header/Footer फरक चाहिन्छ।
  • Page Number Format फरक चाहिन्छ।
  • Margin फरक चाहिन्छ।
  • Column Layout फरक चाहिन्छ।
  • Document को विभिन्न भागमा अलग Page Setup चाहिन्छ।

Page Break भनेको "अबको लेखाइ अर्को Page बाट सुरु होस्" भन्ने आदेश हो।

Section Break भनेको "अबदेखि Document को यो भागको Page Setup वा Formatting फरक हुन सक्छ" भन्ने आदेश हो।

त्यसैले सामान्य रूपमा नयाँ Page मात्र चाहिएको हो भने Page Break प्रयोग गर्नुहोस्। तर Page Orientation, Header, Footer, Margin, Column वा Page Number फरक चाहिएको छ भने Section Break प्रयोग गर्नुहोस्।

Microsoft Word मा राम्रो र व्यवस्थित Document बनाउन Page Break र Section Break को सही प्रयोग अत्यन्त महत्वपूर्ण हुन्छ। धेरै पटक Enter थिचेर Page मिलाउनुको सट्टा Page Break प्रयोग गर्दा Document व्यवस्थित र सजिलै Edit गर्न सकिने हुन्छ।

त्यस्तै, लामो Report, Thesis, Project Work, कार्यालयीय प्रतिवेदन वा पुस्तक तयार गर्दा फरक Page Orientation, Header/Footer, Margin तथा Page Number आवश्यक भएमा Section Break प्रयोग गर्नुपर्छ।
