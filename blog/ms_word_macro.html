MS Word मा Macro को प्रयोग

Developer Tab के हो ?

Developer Tab Microsoft Word को एउटा विशेष मेनु हो जसले प्रयोगकर्तालाई Word लाई सामान्य Document Editing भन्दा अझ उन्नत (Advanced) रूपमा प्रयोग गर्न मद्दत गर्छ।

Developer Tab प्रयोग गरेर Macros बनाउन, Visual Basic (VBA) कोड लेख्न, Form तयार गर्न, Automation गर्न, XML Mapping गर्न तथा विभिन्न प्रकारका Office Add-ins प्रयोग गर्न सकिन्छ।

सामान्य प्रयोगकर्ताले Word मा पत्र, प्रतिवेदन, तालिका आदि तयार गर्न Developer Tab प्रयोग नगरे पनि हुन्छ। तर बारम्बार दोहोरिने कामलाई स्वचालित (Automatic) बनाउन चाहने प्रयोगकर्ताका लागि Developer Tab धेरै उपयोगी हुन्छ।

Developer Tab कसरी ON गर्ने ?

MS Word इन्स्टल भएपछि Developer Tab प्रायः लुकेको (Hidden) अवस्थामा हुन्छ। यसलाई निम्न चरणहरू पूरा गरेर देखाउन सकिन्छ।

  1. File मेनुमा क्लिक गर्नुहोस्।
  2. Options मा क्लिक गर्नुहोस्।
  3. Customize Ribbon चयन गर्नुहोस्।
  4. दायाँपट्टि रहेको सूचीमा Developer मा ✔ चिन्ह लगाउनुहोस्।
  5. OK बटनमा क्लिक गर्नुहोस्।

अब Word को माथिल्लो Ribbon मा Developer Tab देखिनेछ।

Developer Tab भित्र के–के हुन्छ ?

  • Visual Basic
  • Macros
  • Macro Security
  • Add-ins
  • Controls
  • Design Mode
  • XML Mapping
  • Protect Document

Visual Basic (VBA) के हो ?

Visual Basic for Applications (VBA) Microsoft Office भित्र प्रयोग हुने Programming Language हो।

यसको प्रयोग गरेर Word का विभिन्न कार्यहरू स्वचालित बनाउन सकिन्छ। उदाहरणका लागि:

  • एकै पटक सयौं पत्र तयार गर्ने।
  • Document Formatting Automatic गर्ने।
  • Data Import/Export गर्ने।
  • Custom Menu वा Button बनाउने।
  • Repeated Tasks Automatic गर्ने।

Visual Basic Editor कसरी खोल्ने ?

  1. Developer Tab मा जानुहोस्।
  2. Visual Basic मा क्लिक गर्नुहोस्।
  3. VBA Editor खुल्छ।
  4. त्यहाँ Module बनाएर VBA Code लेख्न सकिन्छ।
उदाहरण:

यदि तपाईंलाई प्रत्येक दिन एउटै प्रकारको पत्र बनाउनु पर्छ भने VBA प्रयोग गरेर एउटा Button क्लिक गर्दा पत्र आफै तयार हुने व्यवस्था गर्न सकिन्छ।

Macros के हो ?

Macro भनेको Word मा गरिएका कार्यहरूको रेकर्ड (Record) हो।

कुनै काम बारम्बार गर्नुपर्छ भने त्यसलाई Record गरेर पछि एक क्लिकमै पुनः चलाउन सकिन्छ।

Macro किन प्रयोग गर्ने ?

  • समय बचाउन।
  • दोहोरिने काम स्वचालित बनाउन।
  • त्रुटि कम गर्न।
  • उत्पादकता बढाउन।

Macro कसरी बनाउने ?

  1. Developer Tab मा जानुहोस्।
  2. Record Macro क्लिक गर्नुहोस्।
  3. Macro Name लेख्नुहोस्।
  4. OK क्लिक गर्नुहोस्।
  5. अब Word मा गर्ने कामहरू Record हुन्छन्।
  6. काम पूरा भएपछि Stop Recording क्लिक गर्नुहोस्।

Macro कसरी चलाउने ?

  1. Developer → Macros मा क्लिक गर्नुहोस्।
  2. Macro चयन गर्नुहोस्।
  3. Run क्लिक गर्नुहोस्।
उदाहरण:

यदि प्रत्येक पत्रमा एउटै Header, Footer र Font प्रयोग गर्नुपर्छ भने Macro बनाएर एक क्लिकमै सबै Formatting लागू गर्न सकिन्छ।

Macro Security के हो ?

Macro Security भनेको Word मा रहेका Macros सुरक्षित रूपमा चलाउने वा रोक्ने व्यवस्था हो।

केही Macro हरूमा हानिकारक Code (Virus वा Malware) हुन सक्ने भएकाले Microsoft ले Security सुविधा दिएको हुन्छ।

Macro Security कसरी खोल्ने ?

  1. Developer Tab मा जानुहोस्।
  2. Macro Security मा क्लिक गर्नुहोस्।
  3. Trust Center खुल्छ।
  4. Macro Settings चयन गर्न सकिन्छ।

Macro Security का मुख्य विकल्पहरू

  • Disable all macros without notification
    कुनै Macro चल्न दिँदैन।
  • Disable all macros with notification
    Macro भेटिएमा Enable गर्ने अनुमति माग्छ।
  • Disable all macros except digitally signed macros
    Digital Signature भएका Macro मात्र चल्न दिन्छ।
  • Enable all macros
    सबै Macro चल्न दिन्छ। (सुरक्षाको दृष्टिले सिफारिस गरिँदैन)
सावधानी:

अपरिचित व्यक्तिबाट प्राप्त Word फाइलको Macro तुरुन्त Enable नगर्नुहोस्। हानिकारक Macro ले कम्प्युटरमा Virus वा Malware चलाउन सक्छ।

Developer Tab को प्रयोग कहाँ–कहाँ हुन्छ ?

  • Office Automation System
  • Darta-Chalani System
  • Mail Merge Automation
  • Employee Management System
  • Report Generation
  • Form Design
  • Data Entry Forms
  • Government Office Automation
  • School एवं College Reporting

Developer Tab भनेको MS Word को Advanced Feature हो जसले Word लाई Programming र Automation का लागि प्रयोग गर्न मद्दत गर्छ।

Visual Basic (VBA) प्रयोग गरेर Program लेख्न सकिन्छ, Macro प्रयोग गरेर दोहोरिने काम Record गरेर Automatic गर्न सकिन्छ, र Macro Security प्रयोग गरेर हानिकारक Macro बाट कम्प्युटरलाई सुरक्षित राख्न सकिन्छ।

Office Automation, Mail Merge, Report Generation तथा Government Office Digitalization मा Developer Tab को प्रयोग धेरै हुने गर्दछ।
