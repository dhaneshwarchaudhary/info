MS Excel File खोल्नु अघि Password Protect कसरी गर्ने ?

परिचय

Microsoft Excel मा तयार गरिएको महत्वपूर्ण, व्यक्तिगत वा गोप्य Excel File लाई अनधिकृत व्यक्तिले खोल्न नपाओस् भन्नका लागि Password Protection प्रयोग गर्न सकिन्छ। Password राखेपछि Excel File खोल्दा पहिले Password मागिन्छ र सही Password राखेपछि मात्र File खुल्छ।

यो सुविधा कार्यालयको कर्मचारी विवरण, तलब विवरण, बजेट, लेखा विवरण, परीक्षा परिणाम, विद्यार्थी विवरण, बैंकिङ विवरण, व्यक्तिगत आर्थिक विवरण तथा अन्य संवेदनशील Excel File सुरक्षित राख्न निकै उपयोगी हुन्छ।

१. Excel File मा Password किन राख्ने ?

Computer वा Laptop मा रहेको Excel File अरू व्यक्तिले अनुमति बिना खोल्न, पढ्न वा त्यसमा भएको जानकारी हेर्न नसकोस् भनेर Password राखिन्छ।

  • गोप्य कार्यालयीय विवरण सुरक्षित राख्न।
  • कर्मचारीको तलब तथा व्यक्तिगत विवरण सुरक्षित राख्न।
  • विद्यार्थीको परीक्षा तथा Result विवरण सुरक्षित राख्न।
  • आर्थिक तथा लेखा विवरण सुरक्षित राख्न।
  • बजेट तथा वित्तीय विवरण सुरक्षित राख्न।
  • व्यक्तिगत महत्वपूर्ण Data सुरक्षित राख्न।
  • अनधिकृत व्यक्तिबाट Excel File खोल्न रोक्न।

२. Excel File खोल्न Password कसरी राख्ने ?

Excel File खोल्दा नै Password मागिने बनाउन निम्न चरणहरू पालना गर्नुहोस्।

  1. सबैभन्दा पहिले आफ्नो Microsoft Excel File खोल्नुहोस्।
  2. माथि बायाँतर्फ रहेको File Menu मा क्लिक गर्नुहोस्।
  3. अब Info विकल्पमा क्लिक गर्नुहोस्।
  4. Protect Workbook भन्ने विकल्पमा क्लिक गर्नुहोस्।
  5. देखिएको Menu बाट Encrypt with Password चयन गर्नुहोस्।
  6. अब Password राख्ने Box खुल्छ।
  7. आफूले चाहेको सुरक्षित Password लेख्नुहोस्।
  8. OK मा क्लिक गर्नुहोस्।
  9. फेरि Password Confirm गर्न अर्को Box आउँछ।
  10. पहिले राखेको Password फेरि लेख्नुहोस्।
  11. OK मा क्लिक गर्नुहोस्।
  12. अन्त्यमा Ctrl + S थिचेर Excel File Save गर्नुहोस्।

३. छोटकरीमा Password राख्ने तरिका

Excel File खोल्नुहोस् → File → Info → Protect Workbook → Encrypt with Password → Password राख्नुहोस् → Confirm गर्नुहोस् → Save गर्नुहोस्।

४. Password राखेपछि के हुन्छ ?

Password राखिसकेपछि Excel File बन्द गरेर पुनः खोल्दा Excel ले पहिले Password माग्छ।

Password Required

Enter password to open this file:

Password: __________________

OK    Cancel

सही Password राखेपछि मात्र Excel File खुल्छ। गलत Password राख्दा File खोल्न सकिँदैन।

५. Excel File बाट Password कसरी हटाउने ?

पछि Password आवश्यक छैन भने त्यसलाई हटाउन सकिन्छ।

  1. Password Protected Excel File खोल्नुहोस्।
  2. Password राखेर File खोल्नुहोस्।
  3. File Menu मा क्लिक गर्नुहोस्।
  4. Info मा जानुहोस्।
  5. Protect Workbook मा क्लिक गर्नुहोस्।
  6. Encrypt with Password चयन गर्नुहोस्।
  7. Password Box मा रहेको Password Delete गर्नुहोस्।
  8. Password Box खाली भएपछि OK क्लिक गर्नुहोस्।
  9. Ctrl + S थिचेर File Save गर्नुहोस्।

अब Excel File बन्द गरेर पुनः खोल्दा Password मागिने छैन।

६. Password बिर्सिएमा के हुन्छ ?

Encrypt with Password प्रयोग गरेर Excel File सुरक्षित गरेपछि Password बिर्सनु गम्भीर समस्या हुन सक्छ। Excel ले सामान्य रूपमा बिर्सिएको Password सजिलै देखाउने वा Reset गर्ने सुविधा दिँदैन।

त्यसैले महत्वपूर्ण Excel File मा Password राख्दा Password सुरक्षित स्थानमा राख्नुहोस्। कार्यालयीय File भएमा संस्थाको Password Management Policy अनुसार व्यवस्थापन गर्नु राम्रो हुन्छ।

महत्वपूर्ण सूचना:

Excel File को Password बिर्सिएमा File खोल्न समस्या आउन सक्छ। त्यसैले Password सुरक्षित रूपमा सम्झना राख्नुहोस्।

७. बलियो Password कसरी बनाउने ?

Password अरूले सजिलै अनुमान गर्न नसक्ने हुनुपर्छ। आफ्नो नाम, जन्ममिति, मोबाइल नम्बर वा 123456 जस्ता सजिला Password प्रयोग नगर्नु राम्रो हुन्छ।

बलियो Password मा निम्नमध्ये विभिन्न प्रकारका Character समावेश गर्न सकिन्छ:

  • ठूला अक्षर – A-Z
  • साना अक्षर – a-z
  • अंक – 0-9
  • Special Character – @, #, !, %, $ आदि

उदाहरण: Office@Data#2026!

नोट: माथिको Password केवल उदाहरण हो। वास्तविक File मा यही Password प्रयोग नगर्नुहोस्।

८. Excel मा File Password र Sheet Password बीचको फरक

विषय Encrypt with Password Protect Sheet
File खोल्दा Password माग्छ ? हो होइन
सम्पूर्ण File सुरक्षित गर्छ ? हो मुख्यतः एउटा Worksheet सुरक्षित गर्छ
File को Data हेर्न रोक्छ ? हो File खुलेपछि मात्र Sheet Editing नियन्त्रण गर्छ
Formula/Cell Edit रोक्न यसको मुख्य उद्देश्य होइन हो
गोप्य File का लागि धेरै उपयोगी सीमित उद्देश्यका लागि उपयोगी

९. Protect Sheet र Protect Workbook पनि बुझौं

Protect Sheet

Protect Sheet को प्रयोग Worksheet भित्रका Cell, Formula वा Data लाई अनधिकृत रूपमा परिवर्तन गर्न नदिन गरिन्छ।

उदाहरणका लागि Excel मा कर्मचारीको तलब Formula राखिएको छ भने Formula भएको Cell परिवर्तन गर्न नदिन Protect Sheet प्रयोग गर्न सकिन्छ।

Protect Workbook

Protect Workbook को प्रयोग Workbook को Structure सुरक्षित गर्न उपयोगी हुन्छ। यसले प्रयोगकर्तालाई Worksheet थप्ने, Delete गर्ने, Rename गर्ने वा Move गर्ने जस्ता कार्यमा नियन्त्रण गर्न मद्दत गर्न सक्छ।

तर File खोल्न Password राख्नका लागि Encrypt with Password प्रयोग गर्नुहोस्।

१०. कार्यालयमा Excel Password Protection को प्रयोग

कार्यालयमा निम्न प्रकारका Excel File मा Password Protection उपयोगी हुन्छ:

  • कर्मचारीको Salary Sheet
  • कर्मचारी व्यक्तिगत विवरण
  • कर तथा वित्तीय विवरण
  • Budget तथा Accounting Sheet
  • विद्यार्थीको Result Sheet
  • परीक्षाको Mark Sheet
  • Bank तथा Payment Details
  • गोप्य कार्यालयीय तथ्याङ्क
  • Inventory तथा Stock विवरण
  • Research Data

११. Excel File Email वा WhatsApp मार्फत पठाउँदा

महत्वपूर्ण Excel File Email, Messenger वा अन्य माध्यमबाट पठाउँदा पनि Password Protection उपयोगी हुन्छ।

उदाहरणका लागि:

  1. पहिले Excel File मा Password राख्नुहोस्।
  2. File Save गर्नुहोस्।
  3. Password Protected File पठाउनुहोस्।
  4. Password चाहिँ छुट्टै सुरक्षित माध्यमबाट सम्बन्धित व्यक्तिलाई दिनुहोस्।

यसरी File गलत व्यक्तिको हातमा परे पनि Password बिना खोल्न कठिन हुन्छ।

यदि तपाईं चाहनुहुन्छ कि तपाईंले बनाएको Excel File Password नहाली कसैले पनि खोल्न नसकोस् भने:

File → Info → Protect Workbook → Encrypt with Password

मा गएर Password राख्नुहोस्, Confirm गर्नुहोस् र File Save गर्नुहोस्।

त्यसपछि Excel File खोल्दा पहिले Password मागिन्छ। सही Password राखेपछि मात्र Excel File खुल्छ।

ध्यान दिनुपर्ने मुख्य कुरा के हो भने Protect Sheet र Encrypt with Password एउटै कुरा होइन। File नै खोल्न रोक्न Encrypt with Password प्रयोग गर्नुपर्छ।

Microsoft Excel को Encrypt with Password सुविधा महत्वपूर्ण तथा गोप्य Excel File सुरक्षित राख्ने सरल र प्रभावकारी उपाय हो। यसले Password बिना File खोल्न नदिएर अनधिकृत पहुँचबाट Data जोगाउन मद्दत गर्दछ।

कार्यालयीय Salary Sheet, कर्मचारी विवरण, विद्यार्थी Result, Budget, Accounting तथा अन्य संवेदनशील Data राखिएको Excel File मा यो सुविधा प्रयोग गर्नु उपयोगी हुन्छ।

याद राख्नुहोस्: Password राख्नु मात्र पर्याप्त होइन; Password सुरक्षित राख्नु र आवश्यक अवस्थामा Backup राख्नु पनि उत्तिकै महत्वपूर्ण हुन्छ।
