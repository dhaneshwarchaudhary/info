D-04 Return Form (स्वयं कर निर्धारण आय विवरण)

१. D-04 Return Form के हो ?

D-04 Return Form भनेको आन्तरिक राजस्व विभाग (IRD) द्वारा जारी गरिएको स्वयं कर निर्धारण आय विवरण (Self Assessment Return) हो। यस फाराममार्फत करदाताले आफ्नो वार्षिक आय, खर्च, करयोग्य आम्दानी, कर छुट तथा तिर्न बाँकी करको विवरण स्वयं घोषणा गरी विभागमा पेश गर्दछ। आयकर ऐन अनुसार निश्चित अवस्था भएका व्यक्तिहरूले आर्थिक वर्ष समाप्त भएको निश्चित अवधिभित्र D-04 फाराम अनलाइन पेश गर्नुपर्छ। D-04 फाराम Taxpayer Portal मार्फत अनलाइन भर्न र पेश गर्न सकिन्छ ।

D-04 फाराम प्रायः निम्न करदाताले भर्नुपर्ने हुन्छ:
  • एकभन्दा बढी रोजगारदाताबाट आम्दानी प्राप्त गर्ने व्यक्ति
  • वार्षिक रोजगार आय तोकिएको (वार्षिक ४० लाखभन्दा बढी) सीमाभन्दा बढी हुने व्यक्ति
  • स्वयं कर निर्धारण प्रणाली अन्तर्गत आय विवरण बुझाउनुपर्ने करदाता
  • कर चुक्ता प्रमाणपत्र (Tax Clearance Certificate) आवश्यक पर्ने केही व्यक्तिहरू

२. D-04 Return Form कसरी भर्ने ?

चरण १: IRD Taxpayer Portal मा Login गर्नुहोस्।
चरण २: Income Tax Menu खोल्नुहोस्।
चरण ३: "D-04 Return Entry" मा क्लिक गर्नुहोस्।
चरण ४: आर्थिक वर्ष (Fiscal Year) चयन गर्नुहोस्।
चरण ५: व्यक्तिगत विवरण, PAN, ठेगाना तथा सम्पर्क विवरण जाँच गर्नुहोस्।
चरण ६: रोजगार, व्यवसाय, ब्याज, भाडा वा अन्य स्रोतबाट प्राप्त आय विवरण प्रविष्ट गर्नुहोस्।
चरण ७: कर छुट, अग्रिम कर, TDS तथा कर क्रेडिट विवरण भर्नुहोस्।
चरण ८: प्रणालीले गणना गरेको कर दायित्व (Tax Liability) जाँच गर्नुहोस् ।
चरण ९: Verify गरी Submit बटन क्लिक गर्नुहोस्।
चरण १०: Submission Number सुरक्षित राखी आवश्यक परे Print गर्नुहोस् ।

IRD को SOP अनुसार D-04 Return Entry मार्फत आय विवरण भरी Verify तथा Submit गर्न सकिन्छ र Submission Number भविष्यमा रुझु तथा प्रिन्टका लागि आवश्यक हुन्छ ।

३. D-04 भर्दा आवश्यक विवरणहरू

  • PAN Number
  • Taxpayer Portal User ID / Password
  • वार्षिक आम्दानीको विवरण
  • TDS तथा कर कट्टी विवरण
  • बैंक तथा रोजगारदाता सम्बन्धी विवरण
  • कर छुट र कर क्रेडिट सम्बन्धी प्रमाण

४. D-04 Return नबुझाए के हुन्छ ?

  • आय विवरण पेश नगरेको मानिन सक्छ।
  • आयकर ऐन अनुसार जरिवाना तथा थप शुल्क लाग्न सक्छ।
  • कर चुक्ता प्रमाणपत्र (Tax Clearance Certificate) प्राप्त गर्न समस्या हुन सक्छ।
  • विभागबाट स्पष्टीकरण वा कर परीक्षण (Audit) हुन सक्छ।
  • बाँकी करमा थप ब्याज तथा शुल्क लाग्न सक्छ।

आय विवरण समयमै नबुझाउँदा कर प्रशासन सम्बन्धी विभिन्न कानुनी तथा वित्तीय दायित्व उत्पन्न हुन सक्छन्। करदाताले तोकिएको समयभित्र विवरण पेश गर्नु उपयुक्त हुन्छ।

५. महत्त्वपूर्ण सुझाव

  • Submit गर्नु अघि सबै विवरण पुनः जाँच गर्नुहोस्।
  • TDS विवरण IRD Portal मा मिलेको छ कि छैन हेर्नुहोस्।
  • Submission Number सुरक्षित राख्नुहोस्।
  • आवश्यक परे Return को PDF वा Print प्रतिलिपि राख्नुहोस्।
  • समयसीमा समाप्त हुनुअघि फाराम पेश गर्नुहोस्।
