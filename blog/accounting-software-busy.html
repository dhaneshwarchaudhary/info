BUSY Accounting Software प्रयोग गर्ने सम्पूर्ण मार्गदर्शन

BUSY Accounting Software व्यवसाय, पसल, उद्योग, होलसेल, रिटेल, वितरण कम्पनी तथा सेवा प्रदायक संस्थाहरूमा लेखा (Accounting), स्टक व्यवस्थापन (Inventory Management), बिक्री (Sales), खरिद (Purchase), कर व्यवस्थापन (VAT/GST) र वित्तीय प्रतिवेदन (Financial Reports) तयार गर्न प्रयोग हुने लोकप्रिय Accounting Software हो।

BUSY Software को मुख्य उद्देश्य व्यवसायको दैनिक आर्थिक कारोबारलाई व्यवस्थित, छिटो, सुरक्षित तथा त्रुटिरहित बनाउनु हो। यस सफ्टवेयरको प्रयोग गरेर नगद, बैंक, ग्राहक, आपूर्तिकर्ता, स्टक तथा कर सम्बन्धी सम्पूर्ण विवरण एकै स्थानबाट व्यवस्थापन गर्न सकिन्छ।

BUSY Accounting Software का मुख्य विशेषताहरू

  • Accounting Management
  • Inventory / Stock Management
  • Sales & Purchase Management
  • VAT / GST Management
  • Barcode Support
  • Multi-User Facility
  • Financial Reporting
  • Bank Reconciliation
  • Payroll Management
  • Backup & Restore Facility

१. BUSY Software सुरु गर्ने तरिका

  1. Computer मा BUSY Software खोल्नुहोस्।
  2. User Name र Password प्रविष्ट गर्नुहोस्।
  3. Login बटनमा क्लिक गर्नुहोस्।
  4. मुख्य Dashboard खुल्नेछ।

पहिलो पटक प्रयोग गर्दा नयाँ कम्पनी (Company) सिर्जना गर्नुपर्छ।

२. नयाँ Company Create गर्ने तरिका

  1. Company Menu मा क्लिक गर्नुहोस्।
  2. Create Company चयन गर्नुहोस्।
  3. Company Name लेख्नुहोस्।
  4. Address, Phone Number, PAN/VAT Number प्रविष्ट गर्नुहोस्।
  5. Financial Year चयन गर्नुहोस्।
  6. Save क्लिक गर्नुहोस्।

अब तपाईंको कम्पनी BUSY मा तयार हुनेछ।

३. Master Setup के हो ?

Master Setup भनेको कारोबार सुरु गर्नुअघि आवश्यक आधारभूत विवरणहरू तयार गर्ने प्रक्रिया हो।

  • Account Master
  • Item Master
  • Unit Master
  • Customer Master
  • Supplier Master
  • Tax Category

४. Ledger (Account Master) बनाउने

Ledger भनेको कारोबार हुने व्यक्ति, संस्था, बैंक वा खाताको विवरण हो।

Ledger का उदाहरण

  • Cash Account
  • Nabil Bank
  • Customer Account
  • Supplier Account
  • Salary Account
  • Rent Expense Account

Ledger बनाउने तरिका

  1. Masters Menu मा जानुहोस्।
  2. Account Master चयन गर्नुहोस्।
  3. Add क्लिक गर्नुहोस्।
  4. Ledger Name लेख्नुहोस्।
  5. Group चयन गर्नुहोस्।
  6. Save गर्नुहोस्।

५. Item (Stock) Master बनाउने

बिक्री वा खरिद हुने सामानको विवरण Item Master मा राखिन्छ।

उदाहरण

Item Name Unit Rate
Laptop Pcs 70000
Printer Pcs 15000

Item Create गर्ने तरिका

  1. Masters → Item Master
  2. Add क्लिक गर्नुहोस्।
  3. Item Name राख्नुहोस्।
  4. Unit चयन गर्नुहोस्।
  5. Rate राख्नुहोस्।
  6. Save गर्नुहोस्।

६. Purchase Entry (खरिद Entry)

व्यवसायले सामान खरिद गर्दा Purchase Voucher प्रयोग गरिन्छ।

Purchase Entry गर्ने तरिका

  1. Transactions Menu खोल्नुहोस्।
  2. Purchase Voucher चयन गर्नुहोस्।
  3. Supplier चयन गर्नुहोस्।
  4. Item चयन गर्नुहोस्।
  5. Quantity र Rate लेख्नुहोस्।
  6. Save गर्नुहोस्।

यसपछि Stock स्वतः बढ्छ।

७. Sales Entry (बिक्री Entry)

सामान बिक्री गर्दा Sales Voucher प्रयोग गरिन्छ।

Sales Entry गर्ने तरिका

  1. Transactions → Sales Voucher
  2. Customer चयन गर्नुहोस्।
  3. Item चयन गर्नुहोस्।
  4. Quantity तथा Rate लेख्नुहोस्।
  5. VAT आवश्यक भए समावेश गर्नुहोस्।
  6. Save गर्नुहोस्।

बिक्री भएपछि Stock स्वतः घट्छ।

८. Receipt Entry (रकम प्राप्ति)

ग्राहकबाट रकम प्राप्त गर्दा Receipt Voucher प्रयोग गरिन्छ।

उदाहरण

  • ग्राहकले रु. ५०,००० भुक्तानी गर्‍यो।
  • Receipt Voucher मार्फत Entry गरिन्छ।

९. Payment Entry (भुक्तानी)

आपूर्तिकर्ता, कर्मचारी वा अन्य खर्चको भुक्तानी गर्दा Payment Voucher प्रयोग गरिन्छ।

उदाहरण

  • घरभाडा भुक्तानी
  • तलब भुक्तानी
  • Supplier Payment

१०. Journal Entry

समायोजन (Adjustment), Depreciation, Provision तथा अन्य विशेष लेखा Entry गर्न Journal Voucher प्रयोग गरिन्छ।

उदाहरण

Depreciation A/C Dr.
     To Furniture A/C

११. Stock Management

BUSY Software मा प्रत्येक खरिद र बिक्रीपछि Stock स्वतः अद्यावधिक हुन्छ।

हेर्न सकिने विवरणहरू

  • Current Stock
  • Stock Valuation
  • Stock Summary
  • Low Stock Report
  • Item-wise Report

१२. VAT / Tax Management

BUSY Software ले VAT सम्बन्धी विवरण स्वचालित रूपमा गणना गर्न सक्छ।

  • VAT Sales Register
  • VAT Purchase Register
  • Tax Report
  • Return Filing Data

नेपालमा VAT दर्ता भएका व्यवसायका लागि यो सुविधा अत्यन्त उपयोगी हुन्छ।

१३. Reports हेर्ने तरिका

BUSY Software को सबैभन्दा महत्वपूर्ण पक्ष यसको Reporting System हो।

मुख्य Reports

  • Day Book
  • Cash Book
  • Bank Book
  • Ledger Report
  • Trial Balance
  • Profit & Loss Account
  • Balance Sheet
  • Outstanding Report
  • Stock Report

१४. Profit & Loss Report

व्यवसायले नाफा गर्‍यो वा घाटा भयो भन्ने जानकारी Profit & Loss Report बाट पाइन्छ।

उदाहरण

विवरण रकम
कुल बिक्री 10,00,000
कुल खर्च 7,50,000
नाफा 2,50,000

१५. Balance Sheet

कम्पनीको सम्पत्ति (Assets), दायित्व (Liabilities) तथा पूँजी (Capital) को अवस्था Balance Sheet बाट हेर्न सकिन्छ।

१६. Backup लिने तरिका

Data सुरक्षित राख्न नियमित Backup लिनुपर्छ।

  1. Administration Menu खोल्नुहोस्।
  2. Backup Data चयन गर्नुहोस्।
  3. Folder चयन गर्नुहोस्।
  4. Backup क्लिक गर्नुहोस्।
सुझाव: Backup लाई Pen Drive, External Hard Disk वा Cloud Storage मा सुरक्षित राख्नु राम्रो हुन्छ।

१७. Restore गर्ने तरिका

  1. Administration Menu खोल्नुहोस्।
  2. Restore Data चयन गर्नुहोस्।
  3. Backup File चयन गर्नुहोस्।
  4. Restore क्लिक गर्नुहोस्।

BUSY Software प्रयोग गर्दा ध्यान दिनुपर्ने कुराहरू

  • नियमित Backup लिनुहोस्।
  • Voucher Save गर्नु अघि विवरण जाँच गर्नुहोस्।
  • VAT नम्बर सही राख्नुहोस्।
  • Financial Year सही चयन गर्नुहोस्।
  • User Password सुरक्षित राख्नुहोस्।
  • महिनाको अन्त्यमा Reports मिलान गर्नुहोस्।

BUSY Software का फाइदाहरू

  • लेखा व्यवस्थापन छिटो हुन्छ।
  • Manual Calculation कम हुन्छ।
  • Stock स्वतः अद्यावधिक हुन्छ।
  • नाफा-नोक्सान सजिलै थाहा हुन्छ।
  • VAT तथा कर व्यवस्थापन सहज हुन्छ।
  • Financial Reports तुरुन्त प्राप्त हुन्छन्।
  • समय र लागत बचत हुन्छ।
