D-01 Return Form (स्वयं कर निर्धारण आय विवरण)

१. D-01 Return Form के हो ?

D-01 Return Form भनेको आन्तरिक राजस्व विभाग (IRD) द्वारा साना करदाताहरूका लागि निर्धारण गरिएको स्वयं कर निर्धारण आय विवरण (Self Assessment Return) फाराम हो। वार्षिक कारोबार तोकिएको सीमाभित्र रहेका तथा अनुमानित कर प्रणाली अन्तर्गत पर्ने व्यवसायी वा साना करदाताले आफ्नो आम्दानी, कारोबार तथा कर दायित्व स्वयं घोषणा गर्न यो फाराम प्रयोग गर्छन्। D-01 फाराम अनलाइन Taxpayer Portal मार्फत भर्न र पेश गर्न सकिन्छ।

D-01 फाराम सामान्यतया निम्न करदाताले भर्ने गर्दछन्:
  • साना व्यवसाय सञ्चालन गर्ने प्राकृतिक व्यक्ति
  • पूर्वानुमानित (Presumptive) कर प्रणाली अन्तर्गत पर्ने करदाता
  • VAT मा दर्ता नभएका साना व्यवसायी
  • IRD ले D-01 पेश गर्न योग्य ठहर गरेका करदाता

२. D-01 Return Form कसरी भर्ने ?

चरण १: IRD को Taxpayer Portal मा Login गर्नुहोस्।
चरण २: Income Tax Menu विस्तार (Expand) गर्नुहोस्।
चरण ३: "D-01 Return Entry" मा क्लिक गर्नुहोस्।
चरण ४: PAN Number, Mobile Number र Email प्रविष्ट गरी Register गर्नुहोस्।
चरण ५: प्राप्त Submission Number सुरक्षित राख्नुहोस्।
चरण ६: आर्थिक वर्ष (Fiscal Year) चयन गर्नुहोस्।
चरण ७: वार्षिक कारोबार (Turnover), आम्दानी तथा करसम्बन्धी विवरण प्रविष्ट गर्नुहोस्।
चरण ८: प्रणालीले गणना गरेको कर रकम जाँच गर्नुहोस्।
चरण ९: Verify गरी Submit गर्नुहोस्।
चरण १०: आवश्यक भए Voucher प्रिन्ट गरी कर भुक्तानी गर्नुहोस् वा उपलब्ध डिजिटल माध्यमबाट भुक्तानी गर्नुहोस्।

IRD को D-01 SOP अनुसार करदाताले Taxpayer Portal मा गई D-01 Return Entry प्रयोग गरी Submission Number प्राप्त गर्ने, विवरण प्रविष्ट गर्ने र Return Submit गर्ने प्रक्रिया पूरा गर्नुपर्छ।

३. D-01 भर्दा आवश्यक विवरणहरू

  • PAN Number
  • Mobile Number
  • Email Address
  • आर्थिक वर्ष (Fiscal Year)
  • वार्षिक कारोबार रकम (Turnover)
  • आम्दानी तथा कर विवरण

४. D-01 Return नबुझाए के हुन्छ ?

  • आय विवरण नबुझाएको मानिन सक्छ।
  • आयकर ऐन अनुसार जरिवाना तथा थप शुल्क लाग्न सक्छ।
  • कर चुक्ता प्रमाणपत्र (Tax Clearance Certificate) प्राप्त गर्न कठिनाइ हुन सक्छ।
  • बाँकी करमा ब्याज तथा अतिरिक्त दायित्व सिर्जना हुन सक्छ।
  • कर कार्यालयबाट स्पष्टीकरण वा परीक्षण (Audit) हुन सक्छ।

करदाताले तोकिएको समयभित्र D-01 आय विवरण पेश नगरेमा कर प्रशासन सम्बन्धी कानुनी कारबाही, जरिवाना वा कर चुक्ता प्रमाणपत्र प्राप्त गर्न समस्या आउन सक्ने व्यवस्था रहेको छ।

५. महत्त्वपूर्ण सुझाव

  • Submission Number सुरक्षित राख्नुहोस्।
  • Submit गर्नु अघि सबै विवरण पुनः जाँच गर्नुहोस्।
  • कर रकम सही गणना भएको सुनिश्चित गर्नुहोस्।
  • Return पेश गरेपछि PDF वा Print प्रतिलिपि सुरक्षित राख्नुहोस्।
  • अन्तिम मिति कुर्नु भन्दा अगाडि नै विवरण पेश गर्नुहोस्।

६. निष्कर्ष

D-01 Return Form साना करदाताले आफ्नो कारोबार र कर दायित्व स्वयं घोषणा गर्न प्रयोग गर्ने महत्वपूर्ण आयकर फाराम हो। समयमै तथा सही विवरणसहित D-01 पेश गर्दा कर अनुपालन सुनिश्चित हुन्छ, कर चुक्ता प्रमाणपत्र प्राप्त गर्न सहज हुन्छ र जरिवाना, ब्याज तथा अन्य कानुनी समस्याबाट बच्न सकिन्छ।
