Microsoft Word मा Mail Merge प्रयोग गर्ने तरिका

Mail Merge भनेको Microsoft Word को एउटा विशेष सुविधा हो जसको प्रयोग गरेर एउटै ढाँचाको पत्र, प्रमाणपत्र, नियुक्ति पत्र, तलब पर्चा, निमन्त्रणा पत्र, परिचयपत्र आदि धेरै व्यक्तिका लागि स्वचालित रूपमा तयार गर्न सकिन्छ। यसमा Word फाइल (Main Document) र Excel फाइल (Data Source) लाई आपसमा जोडेर प्रत्येक व्यक्तिको नाम, ठेगाना, पद, तलब, फोन नम्बर आदि विवरण स्वतः राख्न सकिन्छ।

Mail Merge के हो ?

Mail Merge भनेको एउटै Word Document लाई धेरै व्यक्तिका फरक–फरक विवरणसँग संयोजन (Merge) गरी व्यक्तिगत दस्तावेज तयार गर्ने प्रक्रिया हो। उदाहरणका लागि, ५०० जना कर्मचारीलाई नियुक्ति पत्र पठाउनुपर्दा प्रत्येक व्यक्तिको नाम छुट्टाछुट्टै टाइप गर्नुको सट्टा एक पटक मात्र Template तयार गरी Excel मा रहेको विवरण प्रयोग गरेर सबै पत्र स्वचालित रूपमा तयार गर्न सकिन्छ।

Mail Merge का मुख्य प्रयोगहरू

  • नियुक्ति पत्र (Appointment Letter)
  • प्रमाणपत्र (Certificate)
  • तलब पर्चा (Salary Slip)
  • विद्यार्थीको नतिजा पत्र
  • निमन्त्रणा पत्र (Invitation Letter)
  • सिफारिस पत्र
  • कर्मचारी परिचयपत्र (ID Card)
  • कर सूचना तथा सरकारी पत्राचार

Mail Merge का लागि आवश्यक सामग्री

  • Microsoft Word
  • Microsoft Excel
  • डेटा भएको Excel Sheet
  • पत्र वा प्रमाणपत्रको Template

Step 1: Excel Data तयार गर्नुहोस्

सबै विवरण Excel मा Column अनुसार राख्नुहोस्।

SN Name Post Office Address
1 Ram Kumar Accountant ABC Office Kathmandu
2 Sita Devi Officer ABC Office Lalitpur

Excel फाइल Save गरेर बन्द गर्नुहोस्।

Step 2: Word Template तयार गर्नुहोस्

Microsoft Word खोल्नुहोस् र आवश्यक पत्रको ढाँचा तयार गर्नुहोस्। 

मिति: __________

श्री/श्रीमती [Name]
[Address]

विषय: नियुक्ति सम्बन्धमा

तपाईंलाई [Post] पदमा नियुक्त गरिएको जानकारी गराइन्छ।

धन्यवाद।

Step 3: Mail Merge सुरु गर्नुहोस्

  1. Word मा Mailings Tab खोल्नुहोस्।
  2. Start Mail Merge मा क्लिक गर्नुहोस्।
  3. Letters चयन गर्नुहोस्।

Step 4: Excel File जोड्नुहोस्

  1. Select Recipients मा क्लिक गर्नुहोस्।
  2. Use Existing List चयन गर्नुहोस्।
  3. Excel File छान्नुहोस्।
  4. Sheet चयन गरी OK क्लिक गर्नुहोस्।

Step 5: Merge Field राख्नुहोस्

कर्सर आवश्यक स्थानमा राखी Insert Merge Field प्रयोग गर्नुहोस्।

उदाहरण:

श्री/श्रीमती «Name»
«Address»

तपाईंलाई «Post» पदमा नियुक्त गरिएको छ।

Step 6: Preview Results हेर्नुहोस्

  1. Preview Results मा क्लिक गर्नुहोस्।
  2. प्रत्येक व्यक्तिको विवरण सही आएको छ कि छैन जाँच गर्नुहोस्।
  3. Next Record प्रयोग गरी अन्य विवरण हेर्नुहोस्।

Step 7: Merge सम्पन्न गर्नुहोस्

  1. Finish & Merge मा क्लिक गर्नुहोस्।
  2. Edit Individual Documents चयन गर्नुहोस्।
  3. All Records चयन गरी OK क्लिक गर्नुहोस्।

अब सबै व्यक्तिका छुट्टाछुट्टै पत्रहरू नयाँ Word Document मा तयार हुन्छन्।

Certificate Mail Merge उदाहरण

Mail Merge का फाइदाहरू

  • समय बचत हुन्छ।
  • हजारौं पत्र एकै पटक तयार गर्न सकिन्छ।
  • मानवीय त्रुटि कम हुन्छ।
  • व्यक्तिगत विवरण स्वतः भरिन्छ।
  • सरकारी तथा कार्यालय कार्यमा अत्यन्त उपयोगी हुन्छ।
  • Certificate, Salary Slip, ID Card आदि छिटो तयार गर्न सकिन्छ।

सामान्य समस्याहरू

समस्या समाधान
Excel Data नदेखिने Excel File Save गरी बन्द गर्नुहोस्।
नेपाली Font बिग्रिने Unicode Font (Preeti होइन) प्रयोग गर्नुहोस्।
खाली Record आउने Excel मा खाली Row हटाउनुहोस्।
संख्या Format बिग्रिने Excel मा Text Format प्रयोग गर्नुहोस्।
महत्त्वपूर्ण: Mail Merge प्रयोग गर्दा Excel Column Heading मा Space वा Special Character कम प्रयोग गर्नु राम्रो हुन्छ। उदाहरण: Name, Address, Post, Phone जस्ता सरल Field Name प्रयोग गर्दा Mail Merge सजिलै काम गर्छ।
